# RetailPro — Análisis de Datos Comerciales

## Descripción

RetailPro es una empresa distribuidora de tecnología. Este proyecto tiene como objetivo analizar sus datos comerciales para comprender las variaciones en las ventas e identificar oportunidades de mejora a partir del comportamiento de clientes y productos.

## Objetivo del análisis

El objetivo principal es analizar la información comercial de RetailPro para comprender el comportamiento de sus ventas e identificar posibles oportunidades de mejora.

### Pregunta de negocio

¿Qué factores están explicando las variaciones en las ventas de RetailPro y qué combinaciones presentan las mayores oportunidades de mejora?

## Herramientas utilizadas

* *SQL:* creación y ejecución de consultas para analizar los datos comerciales.
* *Power BI:* modelado y visualización de los datos.
* *GitHub:* almacenamiento, organización y documentación de los archivos del proyecto.

## KPIs principales

Los principales indicadores utilizados para analizar el desempeño comercial son:

* Total de ventas.
* Cantidad de unidades vendidas.
* Ticket promedio.
* Cantidad de clientes.

## Scripts SQL

Los scripts SQL permiten consultar y preparar la información necesaria para el análisis. Entre las consultas desarrolladas se encuentran:

* Resumen ejecutivo mensual.
* Ranking de productos por facturación.
* Identificación de clientes recurrentes.
* Comparación de la facturación mensual con el promedio.
* Integración de ventas, clientes, productos y categorías mediante INNER JOIN.

Los resultados obtenidos sirven como base para continuar el análisis y la visualización en Power BI.

## Ejecución de los scripts SQL

1. Descargar o clonar el repositorio de GitHub.
2. Abrir los scripts en un entorno compatible con SQL.
3. Contar con la base de datos y las tablas correspondientes al proyecto RetailPro.
4. Ejecutar los scripts SQL.
5. Revisar los resultados obtenidos en cada consulta.
6. Utilizar los datos resultantes para continuar el análisis en Power BI.

> *Nota:* Los scripts deben ejecutarse sobre una base de datos que contenga las tablas y estructuras utilizadas por las consultas del proyecto.
